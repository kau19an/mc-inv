# mc.faariaz.com

Projetos de Minecraft do Faariaz. Por enquanto, só o **Inventário** (`/inv`): réplica interativa do inventário do Modo Criativo da Edição Java.

- Stack: Astro + Preact, site estático (sem banco)
- Dados: gerados a partir do `client.jar` oficial (fase 2)
- Deploy: Vercel, a partir desta branch (`project/mc-inv`)

```sh
npm install
npm run dev
```
